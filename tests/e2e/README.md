# 실제 WebView E2E 테스트 (`tests/e2e/`)

QA 빌드(`--features qa`)에 포함된 내장 WebDriver로 실제 macOS WebView(WKWebView)를 제어해 UI 동작을 검증하고 라이트·다크 모드 화면을 캡처합니다. Python 표준 라이브러리만 사용하며 배포 패키지나 CI 실행에는 포함되지 않습니다.

## 사전 준비 및 실행

- macOS(Apple Silicon) 및 Python 3.9 이상이 필요합니다.
- 스크린샷은 WebDriver가 WebView 내부에서 직접 캡처하므로 macOS 화면 기록 권한은 필요하지 않습니다.
- `--large` 옵션 실행 시 임시 폴더에 약 400 MB 크기의 합성 로그를 생성합니다.

```sh
CARGO_TARGET_DIR=target/qa cargo build --release --locked -p logstudio-desktop --features qa
python3 tests/e2e/run.py target/qa/release/logstudio-desktop
```

- 별도의 `CARGO_TARGET_DIR`을 지정하면 일반 릴리스 빌드(`target/release`)와 산출물이 섞이지 않습니다.
- 특정 시나리오만 실행하려면 뒤에 이름을 나열합니다(예: `run.py <바이너리> follow reopen`).
- 실행 결과(`results.json`)와 스크린샷은 `artifacts/e2e/`에 저장되며, 실행할 때마다 기존 폴더를 비우고 새로 기록합니다. 결과를 따로 보관하려면 `--out <폴더>`를 지정합니다. 실패한 항목이 있으면 종료 코드 `1`을 반환합니다.
- **백그라운드 실행(기본값):** `LOGSTUDIO_QA_BACKGROUND=1`(QA 빌드 전용)이 기본 적용되어 앱이 비활성 상태(`ActivationPolicy::Prohibited`)로 시작됩니다. 창이 앞으로 나오거나 키보드 포커스를 빼앗지 않고 Dock 아이콘도 나타나지 않아 테스트 중 다른 작업을 할 수 있습니다. 다만 창이 숨김 상태(`document.visibilityState === "hidden"`)이므로 `requestAnimationFrame`은 돌지 않고 포커스·선택 색상이 비활성 창 기준으로 찍힙니다.
- **포그라운드 실행(`--foreground`):** 일반 실행처럼 앱 창을 화면 맨 앞에 띄웁니다. 활성 창 상태의 스크린샷이 필요할 때 사용합니다(`window` 시나리오는 모드와 관계없이 실제 창 위치·크기를 변경함).

## 테스트 격리

- 첫 실행 기능 팁은 다른 시나리오 화면을 가리지 않도록 기본적으로 끄며, `tips` 시나리오(`ctx.launch(tips=True)`)에서만 켭니다.
- 시나리오마다 독립된 임시 `HOME`과 임시 픽스처 폴더를 생성해 최근 파일·작업 상태·창 위치를 격리하고, 시나리오 종료 시 삭제합니다.
- 입력 데이터는 [fixtures.py](fixtures.py)가 생성하는 합성 로그와 저장소의 COVESA 공개 DLT 샘플([../fixtures/covesa](../fixtures/covesa)) 복사본만 사용합니다. DLT 픽스처는 코어의 `dlt::synth`와 독립적으로 검증하기 위해 Python `struct`로 직접 생성합니다.
- 바이너리를 직접 실행할 때 생성되는 WebKit 로컬 저장소(`~/Library/WebKit/<실행 파일 이름>`, 설치형 앱의 `dev.logstudio.desktop`과 별도)는 테스트 종료 시 정리합니다.
- 클립보드 복사는 시스템 클립보드를 건드리지 않고 페이지 내부의 `navigator.clipboard`를 대체(mock)해 검증합니다.

## 한계 및 미검증 영역

- **네이티브 OS 입력 및 대화상자:** 실제 하드웨어 키보드·트랙패드 입력, OS 파일 드래그 앤 드롭, macOS 메뉴 바의 Edit → Paste(⌘V) 및 Finder 파일 붙여넣기, 네이티브 파일 열기·저장 대화상자는 WebDriver로 직접 제어할 수 없습니다. 키 입력·제스처·포인터 이벤트는 페이지 내부의 합성 이벤트로 핸들러 동작을 검증하며, 텍스트 드래그 선택은 `Selection` API로 대체합니다.
- **백그라운드 실행 시 타이밍:** 백그라운드 모드(`document.hidden`)에서는 WebKit이 `requestAnimationFrame`을 멈추고 타이머를 늦추므로, 드래그 자동 스크롤은 동작 여부만 확인하고 컨트롤 이동에 따른 팁 위치 추적은 Node 단위 테스트(`tests/tips.test.mjs`)에서 검증합니다.
- **다크 모드 전환:** OS 설정을 직접 바꾸는 대신 스타일시트의 `prefers-color-scheme: dark` 미디어 규칙을 활성화해 캡처합니다.
- **타 OS:** 이 E2E 테스트는 macOS WKWebView 환경에서만 실행됩니다.
